# MARICEL BUSINESS — Lead Qualification Agent

Projet de data science de qualification et de priorisation de leads B2B.

L'application, le pipeline, les tests et la documentation se trouvent dans [`LLM_agent_for_MARICEL_BUSINESS`](LLM_agent_for_MARICEL_BUSINESS/README.md).

Le pipeline est utilisable localement, sans clé API : il normalise un export CSV, applique un score transparent, produit une analyse par segment et classe les leads. Les fonctions d'enrichissement web et LLM restent facultatives et sont désactivées par défaut.
